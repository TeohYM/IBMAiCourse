AI Agents 工作流工作坊教材

用 IBM Bob 讓 AI 自動串接多個步驟、依序完成任務，不需要任何程式背景。以下是本工作坊示範的四步驟流程：

  1. 1語料獲取閱讀外語新聞
  2. 2語言分析提取生詞與文法
  3. 3知識庫寫入存入 Obsidian
  4. 4網頁發佈產出學習報告

工作坊的核心目標

本工作坊的核心目標，是帶你學會用 IBM Bob 打造屬於自己的 AI 工作流（Agentic Workflow）——讓 AI 自動串接多個步驟、依序完成任務，不需要任何程式背景即可上手。

為了說明 AI 工作流的概念，本工作坊以「AI 外語自學系統」作為範例情境——從閱讀外語新聞、自動提取生詞與文法，到將學習成果存入 Obsidian 筆記庫，完整示範一條四步驟的自動化流程。

💡 學完之後，換你打造自己的工作流

外語自學系統只是一個引路的範例。熟悉工作坊的內容之後，你可以輕易將同樣的思維套用到任何場景——無論是學術研究、文件整理、內容創作，或任何你能想到的應用，都可以用 IBM Bob 打造專屬的自動化工作流。

本工作坊的示例工作流已完整記錄在專案根目錄的 AGENTS.md，可作為設計自己工作流的參考起點。

準備工作

取得工作坊專案檔案。所有教材與設定檔案都存放於 GitHub 專案中，請先將專案下載至你的電腦，才能跟著實作。將下方 prompt 貼給 IBM Bob（Agent 模式），AI 會自動幫你完成 Git 安裝與專案下載，全程不需要你自己輸入任何指令。

🤖 請 AI 幫你安裝 Git 並取得專案檔案

請幫我完成以下兩件事，所有步驟都用命令列工具自動執行，不需要我另外開終端機： 1. 偵測我的電腦是否已安裝 Git： - macOS：先確認 Homebrew 是否存在；若有則執行 brew install git；若沒有 Homebrew，先執行官方安裝腳本安裝 Homebrew，再執行 brew install git - Windows：執行 winget install --id Git.Git 安裝 2. 安裝完成後，執行以下指令下載工作坊專案： git clone --single-branch --branch workshop/w05 \ https://github.com/howard-haowen/ibm-bobathon.git \ ibm-bobathon-w05 完成後告訴我：(a) Git 版本號，(b) 下載的資料夾完整路徑，(c) 資料夾內的頂層檔案清單。
