IBM Bob 進階功能設定

掌握三大模式後，這份筆記整理讓「多語言學習助手」更強大的進階工具：語言學習專屬 Skills、透過 MCP 串接新聞來源，以及 Bob Rules 行為規範設定。

本頁目錄
  1. Skills — 可重複使用的工作流指引模組
  2. MCP Server — 連接外部工具與即時資料來源
  3. Rules — 持久化 Bob 行為規範設定

Skills 的使用

預設路徑 .bob/skills/<skill-name>/SKILL.md

Skill 是一份可重複使用的工作流指引，告訴 Bob 在特定場景下應遵循哪些步驟與最佳實踐。在 Bob 的對話輸入框輸入 /，彈出的選單除了顯示內建命令之外，也會列出所有已安裝的 Skills，可直接選取啟用。本專案已安裝以下語言學習相關 Skills：

Skill 名稱 用途說明
find-skills 協助探索並安裝額外的 Agent Skill。當你詢問「有沒有可以學日文的技能？」或「是否有更好的 RSS 抓取方法？」時，Bob 會透過此 Skill 搜尋技能生態系（skills.sh），提供安裝指令。
language-learning 多語言學習核心 Skill。自動判定 CEFR 層級、提取 8～12 個生詞（含音標、詞性、記憶鉤、Collocations）、剖析 2～3 個句型、補充文化語境，並產出間隔複習閃卡清單。支援英文、日文、法文、德文等多種語言。
obsidian-cli Obsidian 筆記庫管理 Skill。負責將 Bob 產出的學習筆記寫入本機 Obsidian Vault（llm-wiki）的 language-notes/ 資料夾，自動建立 Frontmatter 與 Wikilinks，並在資料夾不存在時自動建立。
markdown-to-html Markdown 轉 HTML Skill。將學習筆記的 .md 檔轉換為 Cheatsheet 風格 HTML，版面精簡、適合列印（A4）或手機閱覽，輸出至同名 .html 檔案。
defuddle 網頁正文萃取 Skill。當 RSS 只有摘要、或你想直接貼網址讓 Bob 抓取全文時使用。透過 URL 抓取完整網頁內容並萃取正文，作為語料分析的輸入。
💡

小技巧

在對話框輸入 / 再輸入 Skill 名稱即可直接啟用，例如輸入 /language-learning，Bob 就會進入語言分析模式。

MCP Server 設定

預設路徑 .bob/mcp.json

MCP（Model Context Protocol）是一套開放標準，讓 AI Agent 能夠以一致的方式呼叫外部工具、存取即時資料，甚至操作本機應用程式。透過 MCP Server，Bob 不再僅限於靜態訓練知識，而能在對話中即時拉取外部資訊——例如直接讀取你 NetNewsWire 的訂閱新聞、抓取網頁原文，或串接資料庫查詢。本專案的語言學習工作流使用兩個 MCP Server 取得外語新聞語料：

本專案目前的 MCP 設定（.bob/mcp.json）：已連接 netnewswire MCP Server（主要來源）與 rss-reader（備用來源）。netnewswire 讓 Bob 直接讀取你在 NetNewsWire 應用程式中訂閱的外語新聞，並取得文章全文。 
{
    "mcpServers": {
        "netnewswire": {
            "command": "npx",
            "args": ["-y", "@modelcontextprotocol/server-netnewswire"]
        },
        "rss-reader": {
            "command": "npx",
            "args": ["-y", "@kwp-lab/rss-reader-mcp"]
        }
    }
}

若您尚未安裝 NetNewsWire，可只使用 rss-reader MCP，搭配專案根目錄的 language-learning-feeds.opml 快速取得各語言的精選學習 Feeds（France 24 法語、朝日新聞日語、DER SPIEGEL 德語、연합뉴스TV 韓語、中央社中文等）。

情境範例：使用 NetNewsWire MCP 列出未讀新聞（Ask 模式）
請透過 NetNewsWire 列出我最新的 10 篇未讀日文新聞，我想選一篇來練日文。
預期 Bob 的回應方向
Bob 呼叫 mcp__netnewswire__get_articles，從你在 NetNewsWire 應用程式中訂閱的 Feed 列出標題、來源媒體與發布時間，讓你直接在對話中選取，無需離開 Bob 介面切換到 NetNewsWire。
情境範例：使用 RSS Reader MCP 從指定 Feed 取得文章（Ask 模式）
請從 language-learning-feeds.opml 裡的法語 Feed 抓取最新 5 篇 France 24 文章，列出標題與摘要讓我選一篇。
預期 Bob 的回應方向
Bob 呼叫 mcp__rss-reader__fetch_feed_entries，傳入 France 24 的 Feed URL（https://www.france24.com/fr/rss），取得最新文章列表後以標題與摘要呈現，適合尚未安裝 NetNewsWire 的使用者。

Rules（行為規範）

預設路徑 .bob/rules/<rule-name>.md

每次重新開啟 Bob 對話，你都必須重新說明「請用繁體中文」、「生詞要附音標」嗎？Rules 解決了這個問題。Bob Rules 是一組存放於 .bob/rules/ 資料夾的 Markdown 檔案，Bob 在每次對話啟動時會自動將這些檔案注入為系統指令，讓你的偏好設定一次、永久生效。Rules 支援三種層級——專案級、模式專屬、全域個人設定——讓你靈活控制規則的作用範圍，避免不同情境下的規則互相干擾。

規則範圍 說明與路徑
專案級（版本控管） .bob/rules/ — 適用於本語言學習專案，隨 Git 版控，換電腦後 clone 即生效。
全域（個人設定） ~/.bob/rules/（macOS/Linux）— 適用於你在所有專案中的 Bob 對話，設定個人語言偏好，不進入版控。

範例：語言學習偏好規則

在 .bob/rules/language-learning-prefs.md 加入以下內容，Bob 就會在每次對話中自動遵守，不需要每次重新說明：

# .bob/rules/language-learning-prefs.md

# 語言學習輸出規範

1. **輸出語言**：所有解說、釋義與文法說明一律使用繁體中文（台灣）。
2. **音標格式**：英文生詞必須附上 IPA 音標；日文生詞必須附上假名讀音。
3. **CEFR 標示**：每個生詞必須標示 CEFR 難度等級（A2 / B1 / B2 / C1 / C2）。
4. **例句品質**：延伸造句必須標明使用場景（職場 / 日常 / 旅遊），不得直譯。
5. **閃卡格式**：複習清單用兩欄表格，左欄為目標語言詞彙（含音標），右欄為繁中釋義。
💡

小技巧

也可以直接告訴 Bob：「請幫我在 .bob/rules/ 建立一個規則檔，要求你一律回應繁體中文、生詞必須附 IPA 音標，以及 CEFR 等級。」Bob 會自動建立內容正確的規則檔。
