文章節錄（原文） LEARNING MATERIAL 
For the past few years, much of the conversation around artificial intelligence in higher education has focused on Generative AI: tools that can answer questions, summarise information, create content and support research.

Use is already widespread. QS research found that 67% of academics and 62% of students use Generative AI at least weekly, suggesting that AI is becoming an increasingly familiar part of university life.

Agentic AI takes this a step further. Instead of simply responding to a prompt, an AI agent can work towards a defined goal, drawing on different systems, making decisions between steps and carrying out routine actions where appropriate.

三種模式一覽

拿到這篇文章後，正確的學習流程是依序切換三個模式，每個模式做它最擅長的事。

Ask

知識模式

閱讀文章、解釋生詞、分析句型、說明文化背景。不會修改任何檔案，適合搞懂文章內容與語言知識。

讀懂文章 解釋生詞 分析句型 文化說明

權限：唯讀。不寫入本地檔案，不執行命令。

Plan

規劃模式

規劃筆記結構、決定要提取哪些生詞、設計閃卡格式。聚焦「學什麼、怎麼記」，在動手前確認方向。

生詞篩選策略 筆記架構設計 CEFR 層級定位 記憶方法規劃

權限：可讀取檔案，僅輸出計畫文字，不直接執行修改。

Agent

執行模式

根據規劃，自動產出生詞卡、文法剖析、閃卡清單，並直接生成 Cheatsheet 風格的 HTML 學習複習頁面。

生成生詞卡 剖析長難句 產出 HTML 建立閃卡

權限：完整讀寫，可呼叫工具、執行 Shell 命令。

實際演練

以上方英語新聞文章為起點，依序示範三個模式的正確用法。

TIP
在對話中輸入 @ 符號（例如 @檔案名稱 或 @資料夾名稱），即可快速將專案中的特定檔案或整個資料夾加入對話上下文，讓 Bob 直接讀取與分析目標內容。

Step 1 — Ask 模式

讀懂文章，確認學習起點

拿到文章，第一步不是馬上整理筆記。先用 Ask 模式，在對話中直接引用本機檔案 @A practical guide to agentic AI in higher education.md，讓 Bob 讀取全文、判斷 CEFR 難度、說明哪些詞彙對你最有學習價值、解釋讓你困惑的長難句。

Prompt — Ask 模式 
我想用 @A practical guide to agentic AI in higher education.md 這篇文章學英文，請判斷它的 CEFR 難度，並告訴我這篇文章對英語學習者最有價值的 3 個生詞是什麼，以及第一段裡最複雜的句子結構是怎麼運作的。
Bob 會回答的內容方向
✓ 判定文章 CEFR 難度：B2–C1（教育科技評論體，詞彙密度中等偏高） ✓ 推薦 3 個高價值生詞：agentic（具代理能力的/自主能動的）、autonomy（自主性/自主權）、governance（治理/監管機制） ✓ 解析長難句：「Instead of simply responding to a prompt, an AI agent can work towards a defined goal, drawing on different systems, making decisions between steps and carrying out routine actions where appropriate.」 → 介系詞片語前置對比 + 主句（S+V+O）+ 連續現在分詞片語（drawing, making, carrying out）做伴隨修飾 ✓ 不修改任何檔案

Step 2 — Plan 模式

規劃生詞筆記的架構與學習策略

Ask 模式已幫你掌握文章難度與核心詞彙。現在切換 Plan 模式，在動手產出網頁之前，讓 Bob 規劃完整的學習目標與內容結構（包含生詞卡、句型剖析與 Cheatsheet HTML 學習網頁）。執行此步驟後，Bob 會在工作區產生一份結構化的規劃文件（如 .plan.md 或 plan-xxx.md），供你在進入 Agent 模式前檢視確認。

Prompt — Plan 模式 
請幫我規劃上面這篇文章的學習計畫，目標包含生詞提取、句型剖析、閃卡設計，以及最終產出 .html 學習複習網頁。請產出一份完整的規劃文件。
Bob 會回答的內容方向
✓ 產生一份結構化規劃文件（.md 檔） ✓ 列出 8～10 個待提取生詞（含 CEFR 等級與選取理由，如 agentic, autonomy, governance, tenure, sprawl 等） ✓ 建議剖析句型：① Instead of... 對比句型結合伴隨分詞構句 ② Rather than... 倒裝與條件句 ✓ 規劃閃卡格式與間隔複習節奏（當日 → 隔日 → 一週後） ✓ 規劃輸出目標：生成獨立的 Cheatsheet HTML 學習複習網頁（.html） ✓ 僅產生/輸出計畫文件，不執行實際的網頁生成或修改

Step 3 — Agent 模式

自動產出學習材料，生成 HTML 學習網頁

學習規劃已在 Plan 模式確認。切換至 Agent 模式，Bob 會自動執行：讀取文章全文 → 生成生詞卡與文法剖析 → 直接產出 Cheatsheet 風格的 HTML 學習複習網頁。

生詞卡產出範例（部分）

autonomy /ɔːˈtɒn.ə.mi/  ·  n.  ·  CEFR C1

【繁中釋義】自主性；自治權（語域：學術 / 正式書面體）

文章例句：Agentic AI refers to AI systems that can plan and complete multi-step tasks with a degree of autonomy.
→「代理型 AI 是指能夠以一定程度的自主性規劃並完成多步驟任務的 AI 系統。」

延伸造句（職場場景）：Senior researchers are given substantial autonomy in designing and conducting their experiments.
→「資深研究人員在設計與進行實驗方面享有相當大的自主權。」

記憶鉤：auto（自己）+ nomos（法律/規則）→ 自己制定規則管理自己 →「自主性、自治」
